No leas los números de las frases y deja una pausa de 1 segundo entre frases.

PARTE 1

Ayer en la mañana tuvimos el daily del proyecto y la verdad todo empezó mal. El deploy del backend falló porque alguien hizo push directo a la branch main sin abrir un pull request. Cuando revisamos los logs vimos que el endpoint del login regresaba un error del servidor y el frontend se quedaba cargando. Mi compañero dijo que era un bug en el query de la base de datos, pero yo pensé que era el cache del server. Abrimos un issue en GitHub, hicimos rollback a la versión anterior y el sistema volvió a funcionar. Después nos pusimos a hacer debug con calma. Resulta que el framework actualizó una dependencia y cambió el formato del token, entonces la API rechazaba todas las peticiones. Lo arreglamos, corrimos los tests, hicimos merge y volvimos a hacer el deploy. En la tarde, en la clase de redes, configuramos un router y un switch en Packet Tracer. El firewall bloqueaba el ping, así que tuvimos que agregar una regla nueva y revisar el gateway. Ya en la noche avanzamos con el proyecto de machine learning: limpiamos el dataset, hicimos el training del modelo en la GPU y medimos el accuracy con un test set aparte. El overfitting estaba muy fuerte, así que agregamos dropout y bajamos el learning rate. Al final subimos todo al repo, actualizamos el README y dejamos el pipeline listo para el sprint de la próxima semana.
